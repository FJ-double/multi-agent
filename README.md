
# GrowthOps Multi-Agent System

一个多Agent自动化运营系统（MVP），实现：

- 自动选题（Trend Agent）
- 内容生成（Content Agent）
- 模拟发布（Publish Agent）
- 数据分析（Analytics Agent）
- 策略优化（Strategy Agent）

## 🚀 运行方式

```bash
python main.py
```

## 🧠 特点

- 多Agent协同
- 自动闭环优化
- 可扩展接入真实API

## 📦 适合

- AI Agent项目展示
- 作业 / 申请材料
- GitHub项目作品集
